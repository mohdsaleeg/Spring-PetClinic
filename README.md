# Spring PetClinic

Spring PetClinic is a sample Spring Boot application for managing a veterinary clinic.

## Technologies Used

- Java 17+
- Spring Boot
- Maven
- Spring Data JPA
- H2 Database
- Git and GitHub

## Project Structure

```text
spring-petclinic/
├── .mvn/
├── src/
│   ├── main/
│   └── test/
├── pom.xml
├── mvnw
├── mvnw.cmd
└── README.md
```

## Run the Application

Make sure Java 17 or newer is installed.

Run the following command:

```bash
./mvnw spring-boot:run
```

On Windows PowerShell:

```powershell
.\mvnw.cmd spring-boot:run
```

Open your browser:

http://localhost:8080
